# Проект: Шаблон АСУ для БСУ с промежуточным бункером

Проект автоматизации  

- Логика управления написана для контроллера KRAX PLC-932
- Визуализация написана на python3+PyQt5

# KRAX.CSV из EXCEL

- Скопировать в буффер столбцы Тип-Наименование-модуль-канал, вставить в krax.csv. 
- Меняем порядок (Наименование = описание, имена каналов вписываем)
  Замена ^(AI|DI|DO);(.*);(.*;.*)$ на ;$1;$3;$2 в VSCODE меняет порядок столбцов

# Запуск

Если запускаем из исходников, то

```
python3 -m <SOURCE_DIR_LOCATION>gui -w <SOURCE_DIR_LOCATION>
```

## Зависимости

PyQt, PyQt5/PyQt6, pyplc, pysca, pygui, opentsdb-py, grafana-client и д.р.
